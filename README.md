# ae-prompt

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Git-native prompt management for AI agent workflows.

Agents accumulate dozens of prompt files that share largely identical content. 
Prompt fixes this: prompts are composed via sections and inheritance, versioned automatically, validated against schemas, and emitted to plain `.md` for downstream consumption. 
No duplication, no drift.
